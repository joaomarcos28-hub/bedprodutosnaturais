# Customer Journey

> Every customer journey has a moment where they almost gave up. Find it. Fix it.

## Scope
Use this skill when mapping customer journeys, identifying friction points, designing multi-channel experiences, or optimizing conversion funnels.

## Principles
1. Journey Over Transaction: Focus on the full experience, not single interactions
2. Emotions Matter as Much as Actions: Map feelings alongside behaviors
3. Every Touchpoint Is a Brand Moment
4. Friction Is the Enemy: Every unnecessary step loses customers
5. Data + Empathy: Combine analytics with qualitative research

## Framework

### Journey Stages (AIDA+)
1. **Awareness**: Customer discovers your product
2. **Interest**: Customer researches and evaluates
3. **Decision**: Customer decides to purchase/sign up
4. **Action**: Customer completes the transaction
5. **Retention**: Customer continues using the product
6. **Advocacy**: Customer recommends to others

### For Each Stage, Document:
- **Touchpoints**: Where do customers interact? (website, email, social, support)
- **Actions**: What do customers do?
- **Thoughts**: What are customers thinking?
- **Emotions**: How do customers feel? (frustrated, confused, excited)
- **Pain Points**: What obstacles do customers face?
- **Opportunities**: How can we improve this stage?

## Common Journey Failure Points
1. Onboarding: Too complex, too slow, requires too much upfront
2. First use: User can''t find the core value quickly enough
3. Upgrade prompt: Feels like a paywall, not a value offer
4. Support: Hard to find, slow to respond
5. Cancellation: Unnecessarily difficult (dark pattern)

## Metrics by Stage
| Stage | Key Metrics |
|---|---|
| Awareness | Traffic sources, brand search volume |
| Interest | Time on site, pages per session |
| Decision | Trial signups, pricing page visits |
| Action | Conversion rate, cart abandonment |
| Retention | DAU/MAU, churn rate, NPS |
| Advocacy | Referral rate, review score |

## Checklist
- [ ] All 6 journey stages mapped
- [ ] Emotions documented for each stage
- [ ] Pain points identified with data
- [ ] Top 3 friction points prioritized
- [ ] Success metrics defined per stage
- [ ] Mobile journey separately documented
