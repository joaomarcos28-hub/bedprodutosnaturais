# Design Trends

> Trends are tools, not rules. Apply them intentionally, not because they are popular.

## Scope
Use this skill when: Modernizing a design, evaluating whether to adopt a trend, selecting design aesthetics for a new project, or helping a client understand current design landscape.

## Principles
1. Trends Serve Users -- Not the Other Way Around
2. Apply Trends Selectively: 1-2 trends per project maximum
3. Timelessness > Trendiness for Long-Term Products
4. Trends Have Half-Lives: What''s modern today is dated in 2 years
5. Brand First: Trends should enhance brand identity, not replace it

## Current Trends (2024-2025)

### Typography
- **Variable fonts**: Single file, infinite variations -- use for expressive headlines
- **Oversized serif headings**: Large, editorial-style type as hero elements
- **Kinetic typography**: Animated text for motion-rich experiences

### Layout & Structure
- **Bento grid layouts**: Modular card-based asymmetric grids (Apple-style)
- **Broken grid layouts**: Intentional overlap and asymmetry for editorial feel
- **Infinite scroll with sections**: Blending scroll and section navigation

### Visual Style
- **Glassmorphism (evolved)**: Subtle blur + transparency, not overdone
- **Noise/grain textures**: Adding depth to flat designs
- **Aurora/mesh gradients**: Soft, multi-color atmospheric backgrounds
- **Dark mode as default**: Intentional dark-first design

### Interaction & Motion
- **Scroll-triggered animations**: Content reveals as user scrolls (Intersection Observer)
- **Micro-interactions**: Subtle feedback for every user action
- **Cursor customization**: Custom cursors for portfolio/creative sites
- **Page transitions**: Smooth page-to-page navigation

### Components
- **Command palette (Cmd+K)**: Keyboard-first navigation pattern
- **AI-native UI patterns**: Chat interfaces, streaming text, tool visualization
- **Bottom sheets on mobile**: Native app feel in web

## Application Rules
- DO: Apply max 1-2 trends per project
- DO: Test trend adoption with users before full implementation
- DO: Ensure trends don''t compromise accessibility
- DON''T: Use a trend that slows page load significantly
- DON''T: Adopt trends that contradict your brand positioning

## Checklist
- [ ] Trends selected enhance, not replace, brand identity
- [ ] Trend application tested on mobile
- [ ] No trend reduces accessibility score
- [ ] Performance impact measured before/after
